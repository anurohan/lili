# Lili AI Assistant

A browser-based AI assistant project with a web interface and Python backend components.

## Project files

- `index.html`, `script.js`, and `style.css` provide the browser-facing interface.
- `app.py` and `backend/` contain the Python-side application code.
- `start_lili.bat` is the repository's Windows launch helper.

Review the backend configuration before starting the application. Do not commit API keys or other secrets.
